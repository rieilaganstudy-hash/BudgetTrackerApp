# Budget Tracker App

A simple Android app for tracking monthly grocery budgets and spending.

## Features
- Monthly budget limit
- Grocery expense tracking
- Category-based spending
- Remaining budget calculation
- Expense list with delete option
- SQLite persistence with Room

## Tech stack
- Kotlin
- Jetpack Compose
- Room database
- ViewModel
- Material 3

## Run locally
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or Android device.

## Project structure
- `app/src/main/java/com/budgettracker/app` — app logic and UI
- `app/src/main/res` — resources
